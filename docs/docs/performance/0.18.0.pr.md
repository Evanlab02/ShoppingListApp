# Performance review - V0.18.0 (Pre-release)

These are the performance results from the pre-release version of 0.18.0.

These tests are run with:
- Postgres DB setup with 2 CPU cores and 2GB of RAM.
- Django application is run with 9 workers using 8 CPU cores and 8GB of total RAM.
- All requests are through caddy that is running with 1 CPU core and 1GB of RAM.

## Overview

- `/api/v1/stores/create`
    - Average 750 rps
